Online Food Delivery Full Stack Project
Full-stack food delivery app built during Capgemini 5G RAN training. Features React frontend, Spring Boot backend, MongoDB database, and RazorPay payments.

Tech Stack
Frontend: React, HTML/CSS/JS

Backend: Spring Boot REST APIs

Database: MongoDB

Payments: RazorPay integration

Deployment: AWS-ready (pending)

Tools: VS Code, IntelliJ, MongoDB Compass [user-information]

Features
User authentication & restaurant browsing

Menu search, cart management

Order placement with RazorPay

Admin dashboard for restaurants

Setup & Run
text
# Backend
cd foodiesapi
mvn spring-boot:run

# Frontend  
cd foodies
npm install
npm start
Connects to MongoDB local/remote. Portfolio project for full-stack interviews.
